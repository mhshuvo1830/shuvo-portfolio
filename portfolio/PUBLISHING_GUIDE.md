# Publish the portfolio using GitHub Pages

This website uses HTML, CSS, and JavaScript and can be hosted for free as a static site on GitHub Pages. No Python/Streamlit or build step is needed.

1. Open https://github.com/new and create a **public** repository called `shuvo-portfolio` in your account `mhshuvo1830`. If this name is already taken, choose another name and adjust the website URL accordingly.
2. Extract the ZIP on your computer, then open the `portfolio` directory. On your GitHub repository, choose **Add file → Upload files** and drag in all of the **files inside** `portfolio`: `index.html`, `styles.css`, `script.js`, `headshot.jpeg`, `resume.pdf`, `README.md`, etc. Don't upload just the ZIP or a nested `portfolio` folder: GitHub Pages needs `index.html` at the repository root.
3. Click **Commit changes**. If prompted, commit to `main`.
4. Open **Settings → Pages** within the repository. Under **Build and deployment** select **Deploy from a branch**, select branch **main** and folder **/ (root)**, and click **Save**.
5. Wait several minutes for deployment and refresh the Pages settings. GitHub shows a **Visit site** link once ready.
6. With this repository name, your expected website URL is:
   https://mhshuvo1830.github.io/shuvo-portfolio/

To update the website later, edit and commit the files in the same repository. The live site will be updated automatically after GitHub republishes it.
